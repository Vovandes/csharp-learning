# Программа: C# с нуля

## Модуль 1. Старт
Что такое .NET, CLR, IL, компиляция. Первый консольный проект в Visual Studio и через dotnet CLI. Top-level statements и Main. Console.WriteLine, ReadLine. Чтение ошибок компилятора.
Мини-проект: калькулятор двух чисел.

## Модуль 2. Данные
Типы: int, long, double, decimal, char, bool, string. var. const и readonly. Преобразования, Parse/TryParse. Арифметика и переполнение (checked). Интерполяция строк.
Мини-проект: конвертер валют/единиц.

## Модуль 3. Управление
if/else, switch и switch-выражения, циклы for, while, do-while, foreach. break, continue. Отладчик Visual Studio.
Мини-проект: игра «угадай число».

## Модуль 4. Методы
Параметры, возврат, перегрузка, необязательные и именованные аргументы. ref, out, in. Рекурсия. Локальные функции. Область видимости.
Мини-проект: набор утилит для строк и чисел.

## Модуль 5. Массивы, строки, файлы
Массивы, многомерные массивы. string подробно, StringBuilder. File, StreamReader/Writer, Path, Directory.
Мини-проект: список дел с сохранением в файл.

## Модуль 6. Типы и память
Значимые и ссылочные типы, стек и куча, boxing. null и nullable reference types. Сборщик мусора (GC). struct против class.
Мини-проект: задачи «где живёт и что скопируется».

## Модуль 7. Классы
Поля, свойства, методы, конструкторы, static. Модификаторы доступа. Инкапсуляция. record и record struct. Equals/GetHashCode. Перегрузка операторов.
Мини-проект: класс Fraction (дробь).

## Модуль 8. ООП
Наследование, virtual/override, abstract, sealed. Интерфейсы, реализации по умолчанию. Полиморфизм. Композиция против наследования. SOLID в базовом виде.
Мини-проект: фигуры через интерфейс IShape.

## Модуль 9. Коллекции и обобщения
List<T>, Dictionary<TKey,TValue>, HashSet<T>, Queue, Stack. Generics, ограничения where. IEnumerable и yield return.
Мини-проект: частотный словарь слов.

## Модуль 10. Делегаты и LINQ
Делегаты, Func, Action, лямбды, события. LINQ: Where, Select, OrderBy, GroupBy, Join, агрегаты. Отложенное выполнение.
Мини-проект: отчёт по CSV-файлу через LINQ.

## Модуль 11. Ошибки и ресурсы
Исключения, try/catch/finally, свои исключения. IDisposable, using. Когда исключение, а когда TryXxx/Result.
Мини-проект: надёжный парсер конфигурации.

## Модуль 12. Асинхронность
Task, async/await, ConfigureAwait (знакомство), отмена через CancellationToken. Parallel, потокобезопасность, lock. HttpClient.
Мини-проект: асинхронная загрузка нескольких файлов из интернета.

## Модуль 13. Современный C#
Pattern matching, switch-выражения, кортежи, деконструкция, Span<T>, init, required, primary constructors.
Мини-проект: рефакторинг старого кода на современный синтаксис.

## Модуль 14. Данные и сериализация
System.Text.Json, XML (XDocument), работа с конфигами. Знакомство с EF Core и SQLite.
Мини-проект: справочник контактов на SQLite.

## Модуль 15. Инструменты и приложение
Solution и несколько проектов, NuGet. Тесты xUnit. Логирование. Git и GitHub. Знакомство с WPF или WinForms.
Итоговый проект: приложение на выбор (консоль или WPF) с тестами и README.

Контрольная в конце каждого модуля: 10 вопросов + задача.
